# Progress Hub — regras fictícias para demonstração de RAG

Este arquivo é um exemplo didático. Não representa regras reais do produto.

## Missões diárias
Concluir uma missão diária concede 300 XP. A recompensa só é recebida uma vez por missão.

## Missões semanais
Concluir uma missão semanal concede 1.500 XP.

## Temporadas
Cada temporada dura 30 dias. Ao final, o ranking da temporada é reiniciado.
O XP total do perfil é preservado.
